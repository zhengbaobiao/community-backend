================================================================================
                           快速启动
================================================================================

【环境要求】
  • JDK 1.8+
  • Maven 3.6+
  • MySQL 8.0+
  • Redis 6.x+

【启动步骤】

1. 初始化数据库
   mysql -u root -p < sql/init.sql

2. 修改配置（如需要）
   编辑 src/main/resources/application.yml

3. 启动项目
   Linux/Mac: ./start.sh
   Windows: start.bat
   或: mvn spring-boot:run

4. 访问Swagger
   http://localhost:8080/admin-api/swagger-ui.html

5. 测试登录
   默认账号: admin / admin123
